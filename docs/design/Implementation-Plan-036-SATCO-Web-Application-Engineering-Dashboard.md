# Implementation-Plan-036 — SATCO Web Application & Engineering Dashboard

## Batch 1 — Frontend Foundation

S01 toolchain, typed API/auth boundary, tokens/primitives, shell and routing.
Evidence: unit/API mapping, auth, build, type, shell accessibility. Stop on
client authority, unsupported backend contract, or unbounded dependency.

## Batch 2 — Operational and Customizable Dashboard

S02 dashboard queries/widgets; S03 versioned local layout customization,
recovery, keyboard and drag/drop behavior. Evidence: state matrices,
non-sensitive persistence, responsive grid, no fake totals.

## Batch 3 — Engineering Workflows

S04 Projects and Project Workspace; S05 Journal, Reports, Memory, and AI
Assistant integration. Evidence: typed mapping, protected states, Human/AI
distinction, contextual navigation, bounded requests.

## Batch 4 — Product Hardening and Final Evidence

S06 responsive/accessibility/visual hardening; S07 focused and adjacent tests,
production build, backend regressions, visual/UX review, QG-M1, final evidence.

Every batch receives an exact file manifest, focused validation, Independent
Review, and Human Acceptance. No batch may add a backend domain capability.
