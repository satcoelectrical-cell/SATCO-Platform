# ADR-004

Status: Accepted

Title:
JWT Authentication Architecture

Description:
SATCO Platform uses JWT-based authentication as the foundation of user identity management.

Authentication logic is separated from API routes and follows the layered architecture:

Router Layer
→ Service Layer
→ Repository Layer
→ Database Layer

Passwords are never stored in raw form. Passwords are hashed using secure hashing mechanisms before database storage.

The authentication system uses two token types:

- Access Token for API authorization
- Refresh Token for session renewal

Authentication dependencies are responsible for validating JWT tokens and protecting API endpoints.

This decision provides the foundation for future Role-Based Access Control (RBAC) implementation.

## PATCH-017.3 Clarification

Public registration does not accept role selection. The backend assigns the `engineer` role server-side and validates supported persisted roles through the central Role enum.

The login endpoint uses the OAuth2 password form contract. Username and password must not be supplied through URL query parameters.
